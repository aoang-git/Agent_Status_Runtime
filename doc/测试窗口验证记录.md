- 连接文件：缺失、损坏、非 HTTP / 非 loopback、嵌入凭据或查询参数拒绝；错误信息不暴露令牌。
- HTTP：Bearer 鉴权、401、安全错误消息；重试重新读取令牌，取消后退出；退避为 1、2、5、10、10 秒。
- SSE：逐字节 UTF-8 分段、CRLF、多行 data、心跳、未完成帧、读取超时和超大未终止行。

- 事件队列：最多 500 条，清空不丢失会话和游标。
- 权威快照核对：更新静默会话新鲜度、删除被替换的旧来源，不消费 SSE 游标；旧事件不能覆盖已核对的新状态，仍保留事件记录。
- 真实集成：独立临时 Runtime 读取人工构造 Codex JSONL；追加 `task_complete` 后，客户端由 working 变为 idle/completed，恰好接收一次 `turn.ended`。结束后仅清理测试进程与临时目录。

## 发布版人工验证

通过原生 Windows 窗口操作与截图检查实际发布 EXE：

1. 无参数启动，自动发现项目 `.runtime/live`；实际服务版本 0.1.0。最终核对 CLI 与窗口均为 59 个会话（Claude 31、Codex 15、DeepSeek 10、Pi 3）、75 个来源、10 个降级/不可用来源。数量随真实日志变化。
2. Codex 筛选显示 15 / 59；完整身份和中文详情分行显示；诊断包含根目录、文件通知、来源格式、降级原因和四类 Agent 能力。
3. 手动启动专用测试 Runtime，窗口仅连接它。向测试目录内构造日志追加完成记录后，API 与窗口更新为“空闲 / 明确回合完成”。未向真实 Agent 日志注入数据。
4. 停止专用 Runtime 后，窗口显示“未连接”，保留最后快照及接收时间；窗口没有拉起服务。
5. 手动重启同一测试数据目录的 Runtime，监听端口和令牌变化；窗口自动重读连接信息并恢复连接，事件页仍只有一次明确完成，没有重复历史提醒。
6. 实时事件页暂停自动滚动可勾选，清空后列表为空，连接保持正常。关闭测试窗口后服务继续运行；测试收尾只停止专用 Runtime，真实 Runtime 始终为原 PID 31620。

视觉检查修正了初始 DPI 基线导致的控件缩小，以及详情换行符导致的单行显示。当前正常监测、断线保留快照、来源降级及事件页截图已检查。使用 PerMonitorV2；150% 缩放已做自动化布局检查，实体多显示器 DPI 切换尚未验证。

## 使用边界

窗口不安装 Hooks，不更改 Agent 配置，不启动、停止或配置 Runtime；没有模拟演示、托盘或 Agent 控制功能。显示内容受文件证据限制，未知和推断等待不等于确认完成。首次 snapshot/reset 只建立历史视图；500 条窗口事件记录不保证完整历史。
