# v0.2 验证与交付记录

验证日期：2026-10-23，Windows x64。协议为 v2，Runtime 0.2.0，窗口解释规则 `default-v1`。

## 自动化验证

- Go 16 项测试和 `go vet ./...` 通过。公共样本包含 9 条有效、14 条无效输入及 7 组解释案例；覆盖输出 Schema、四类文件事实、半行／压缩半帧、批次顺序、历史恢复、事务回滚、文件重建、独立读写权限、幂等冲突、来源序号、4096 条重放与 reset、32 个 operation 和快照大小边界。
- 新增诊断身份碰撞测试：同一 producer 的 `(agent=ab,namespace=c)` 和 `(agent=a,namespace=bc)` 保持独立，避免拼接名称丢失来源诊断。
- Windows 客户端 25 项测试全部通过，无跳过。覆盖 SSE 分段、401、45 秒无数据超时、连接文件损坏／非本机拒绝、去重、历史／reset 不通知、500 条上限、并发工具与审批、晚到旧执行、消息截断、分支、证据过期、外部完成与 namespace 隔离。另有先失败后修复的 WinForms 事实详情选择／刷新回归测试。
- 真实链路集成使用独立临时 Runtime：人工 Codex 文件追加后收到唯一完成通知；通用 CLI 报告新 Agent 后，事实持久化进入快照与 SSE，客户端显示外部完成；复用相同事件 ID 不再次通知。
- 离线窗口测试检查最小尺寸和 150% 程序缩放后的布局、按钮尺寸及可关闭性，不创建服务或连接文件。此项不等于实测多台高 DPI 显示器之间迁移。
- 独立窗口构建脚本 `scripts/build-test-window.ps1 -Test` 实际执行通过，发布 Windows x64 自包含 EXE；不会构建或覆盖 Runtime。
- Windows、Linux amd64、macOS arm64 Runtime 均构建成功；后两者仅交叉编译，未声称实机验收。

## 通用接入示例

PowerShell 7 与 Python 标准库示例分别验证 CLI 和直接 HTTP，共四种路径。仅向隔离 Runtime 提交人工 `state.reported/self_report`：8 次重复发送只保存 4 条事实，成功与失败都保持 Hook stdout 为空。缺失连接、挂起服务和 401 凭据轮换测试通过；两种直接 HTTP 实现均重读连接文件，最多两次发送。

一秒预算覆盖发送或 CLI 子进程等待；PowerShell／Python 解释器启动另有开销。示例不构成 Claude／Pi 专用插件认证，未修改 Agent 配置或真实 Agent 日志。

## 窗口检查

用独立 `.runtime/v2-qa` 人工来源检查会话、事实与通知、详情、诊断、中文长名称和最大化布局。明确文件完成显示绿色通知，外部完成保留“外部报告”与声明依据；Claude／Pi 正常消息结束显示“空闲（推断）”。事实详情保留原生／Runtime／客户端时间、来源、执行 ID 和范围。选择行在诊断刷新后保留。

## 正式切换

已验证旧进程路径、数据目录与监听参数后停止 v0.1，备份二进制及停止后的整个 private 目录，再成对更新 Runtime 与窗口。新服务监听原 `127.0.0.1:9120`，使用独立 `facts-v2.sqlite`。只读令牌写入、写令牌读取均返回 403；旧 `state.sqlite` 及其 WAL／SHM 哈希保持不变。

切换时 API／CLI 均返回 51 个来源会话账本，汇总为 43 个统一会话，窗口数量一致。v2 从现存文件重建事实，不导入旧数据库中累积的推断状态，因此数量不要求与 v0.1 历史状态行数相等。

当时真实来源 52 个：42 个健康，9 个因历史 DSH 格式不受支持而降级，1 个超过单行读取上限。保留诊断原因，没有把降级或静默解释为完成。

后续当前 Codex 会话超过 32 个 operation，快照按规则裁剪旧历史并显示 partial；其 incomplete_operations 为空，当前执行仍可解释。该提示表示快照不是完整历史，不是本次网络丢包的证明。

旧版备份：`.runtime/rollback-v0.1-20261023-020049`，含原启动参数、二进制和受限数据库备份；回滚步骤见 [接入协议](v0.2接入协议.md#迁移与回滚)。所有隔离测试进程已结束；正式 Runtime 与窗口保持运行。

已生成 `.runtime/Agent自助接入提示词.md`，包含当前可执行文件路径、数据目录、完整输入规范及实现要求，不含令牌。也可随时运行 `agent-statusd integration-prompt --data-dir <目录>` 离线重新生成。

首版不保证任意工具即刻兼容，不保证离线报告不丢失；协议校验和 native_event 声明均不能证明外部报告真实性。
