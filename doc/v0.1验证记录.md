## 本机真实目录发现

最终扫描观察到 73 个来源、58 个会话：Codex 14、Claude 31、DeepSeek 10、Pi 3。该数量会随本机使用变化，不是兼容率指标。

来源中 63 个健康；9 个 DeepSeek 旧/未知格式来源返回 `unsupported_deepseek_format`，1 个超大记录来源返回 `line_limit_exceeded`。这些来源保持降级，不绕过安全游标，也不制造成功通知。

本机安装元信息：PATH 中 Codex CLI 为 `0.130.0-alpha.5`，已观察的桌面 rollout 标记为 `0.163.0-alpha.10.2`；Claude CLI 为 `2.1.267`；DeepSeek npm CLI 包为 `0.1.5-rc.3`，Pi 包为 `1.2.0`。CLI 版本不能替代桌面内置引擎版本。仅核对结构与白名单元信息，未把这些版本声明为全生命周期认证范围。

监测进程使用文件通知与 5 秒补偿扫描。一次运行采样的 Working Set 为约 55 MiB；未做长时间性能基准，不据此提供资源 SLA。

## 当前运行与操作

服务已作为隐藏后台进程启动，仅监听 `127.0.0.1:9120`；数据位于项目 `.runtime/live/private`。没有注册自启动，没有安装或修改 Agent Hooks。

在项目根查询：

```powershell
.\bin\agent-statusd.exe status --data-dir .\.runtime\live
.\bin\agent-statusd.exe doctor --data-dir .\.runtime\live
.\bin\agent-statusd.exe watch --data-dir .\.runtime\live
```

本次后台进程 ID 记录在 `.runtime/live.pid`。停止前校验进程路径，避免 PID 被复用：

```powershell
$runtimePid = [int](Get-Content .runtime/live.pid)
$process = Get-Process -Id $runtimePid
if ($process.Path -eq (Join-Path (Get-Location) 'bin\agent-statusd.exe')) {
    Stop-Process -Id $runtimePid
}
```

随后可按 README 前台启动，使用 Ctrl+C 正常退出。
